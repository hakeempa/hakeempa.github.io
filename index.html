How I work

Good interfaces are built in layers. I look after each one, so the screen people see rests on parts that are consistent, tested and easy to change.

  • Component systems

    Screens assembled from reusable, documented parts. I build and theme them with Storybook, PrimeNG, Kendo UI, SCSS and Bootstrap 5, so a new screen reuses what is already tested.

  • State and data flow

    Predictable state with NGXS and RxJS streams, so screens that juggle a lot of live data stay fast and easy to reason about as the product grows.

  • AI-driven, full-stack delivery

    Turning designs into accessible, responsive front ends and the NestJS, Node.js or PHP services behind them, working with Claude Code and Augment Code to move faster without cutting corners.

  • Leading and deploying

    As team lead and forward deployed engineer, I keep the team close to the people using the product, so what we ship answers their real needs and lands well in production.
